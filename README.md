# PlaceMate — Smart Placement Management System

A responsive React + Vite frontend for connecting students, recruiters and placement teams.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Stack
- React + Vite
- React Router DOM
- Framer Motion
- Recharts
- Lucide React
- Axios (ready for API integration)

## Current UI
- Public landing page
- Login and role-based registration screens
- Student, recruiter and admin dashboard views
- Job discovery, recommendations, application tracking and profile screens
- Responsive sidebar, charts, status indicators and micro-interactions

## Important integration note
The current frontend uses clearly illustrative development fixtures. Login navigation is a UI demonstration, not real authentication. Connect the Java Spring Boot REST API, JWT authentication and role-based authorization before using real accounts or student data. Admin accounts should be provisioned securely by the placement team, never through public registration.
